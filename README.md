# DarkTube

An open-source browser extension designed to invert the colors of YouTube videos, significantly reducing glare and saving your eyes during late-night browsing or in low-light environments.

## Features

* **Seamless Integration:** Automatically adds a dedicated mode button directly inside the YouTube video player for quick toggling.
* **Eye-Friendly:** Reduces the harsh blue light and extreme brightness of standard video players.
* **Lightweight:** Minimal impact on browser performance and video loading speeds.
* **Privacy-First:** Operates entirely locally on your machine. No tracking, no analytics, and no data collection.
* **100% Open-Source:** Free to use, modify, and distribute.

## Installation

### For Google Chrome, Brave, and Edge (Chromium)

1. Download this repository as a `.zip` file and extract it, or clone it using `git clone`.
2. Open your browser and navigate to the extensions page (`chrome://extensions/` or `edge://extensions/`).
3. Enable **Developer mode** (usually a toggle in the top right corner).
4. Click **Load unpacked**.
5. Select the extracted `DarkTube` folder.

### For Mozilla Firefox

1. Download or clone this repository.
2. Open Firefox and navigate to `about:debugging#/runtime/this-firefox`.
3. Click on **Load Temporary Add-on**.
4. Navigate to the `DarkTube` folder and select the `manifest.json` file.

# DarkTube
Open-Source Extension to Invert YouTube videos color and save your eyes 😊


### How to add Button to Media Player

Add the code below to `.ytp-right-controls-left`

```html
    <button class="ytp-button">
    <svg>
        // Any Svg Data
    </svg>
    </button>
```
